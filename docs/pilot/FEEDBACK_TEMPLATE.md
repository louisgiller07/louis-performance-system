# NALYNT — Feedback du pilote

## Cadence

| Moment | Format |
|---|---|
| Semaine 0 | Onboarding + vérification du premier plan, avec l'équipe |
| Semaine 1 | Feedback rapide (ci-dessous) |
| Semaine 3 | Feedback de mi-pilote : feedback rapide + échange court |
| Semaine 6 | Feedback final / entretien |
| Incident critique | Immédiatement, format « Incident » |

Pas de questionnaire quotidien.

---

## Feedback rapide (semaines 1, 3 et 6)

1. **Combien de jours as-tu utilisé NALYNT cette semaine ?** (0 à 7)
2. **Les séances proposées étaient-elles claires ?** (1 = pas du tout, 5 = très claires)
3. **As-tu suivi les adaptations proposées ?** (1 = jamais, 5 = toujours)
4. **Y a-t-il eu une séance qui n'avait pas de sens ?** Si oui, laquelle et pourquoi ?
5. **Qu'est-ce qui t'a le plus aidé ?**
6. **Quel est le principal problème à corriger ?**

---

## Incident

À envoyer dès que quelque chose ne marche pas :

- **Date** (et heure approximative) :
- **Écran** (Aujourd'hui, Programme, Configuration, Historique…) :
- **Ce que tu voulais faire** :
- **Ce qui s'est passé** :
- **Capture** (si possible) :

N'envoie pas de détails médicaux par message : ce que tu as déclaré dans ton check-in suffit, l'équipe le retrouve si nécessaire. Pour une douleur, un choc ou des symptômes inquiétants, consulte un professionnel de santé.
