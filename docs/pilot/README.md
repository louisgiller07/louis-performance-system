## Cohorte (verrouillée)

**Taille :** 5–8 athlètes.

**Profil :**
- Downhill ;
- niveau intermédiaire à compétitif ;
- semaine d'entraînement stable ;
- accès régulier à du matériel de musculation ;
- accès à des sentiers / un bike park ;
- joignable directement pendant le pilote ;
- courses connues à l'avance de préférence.

**Exclus au départ :**
- athlètes purement endurance ;
- athlètes en rééducation / actuellement blessés ;
- semaines très irrégulières ;
- profils multi-disciplines complexes ;
- athlètes avec un matériel très limité.

Le pilote n'est pas élargi au-delà de ce profil.

## Durée (verrouillée) : 6 semaines

Six semaines couvrent :
- la génération du plan ;
- le passage de la limite de projection glissante à J+14 ;
- les daily-runs répétés ;
- les séances manquées ;
- l'historique de séances enregistrées ;
- un éventuel contexte de course ;
- la rétention en semaines 5–6.

Le plan généré pour chaque rider dure 6 semaines.
